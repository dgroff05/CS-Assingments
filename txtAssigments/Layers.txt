1. The machine's name is "csciarch03". The command I used to obtain this was "hostname".

2. Java and Python are two high-level languages supported. The Java command is "java -version" and the Python command 
is "python --version". These commands verify the languages are supported by showing their verion available on the machine.
Python and Java specifically use compilers to translate the code into bytecode. This bytecode is able to be executed by a Java 
Virtual Machine for Java and a Python Virtual Machinefor Python.

3. The GNU Assembler is installed. I found this out by using the command "as -version". This gave me the name of the assembler 
as well as its current version of 2.45.0. Here is x86 assembly example code for hello world:
.section .data
    msg:    .asciz "Hello, World!\n"
    len =   . - msg

.section .text
.globl _start

_start:
    ; syscall for write (sys_write = 1)
    mov     $1, %rax        ; System call number for sys_write
    mov     $1, %rdi        ; File descriptor (1 for stdout)
    mov     $msg, %rsi      ; Address of the string to write
    mov     $len, %rdx      ; Length of the string
    syscall                 ; Invoke the system call

    ; syscall for exit (sys_exit = 60)
    mov     $60, %rax       ; System call number for sys_exit
    xor     %rdi, %rdi      ; Exit code 0
    syscall                 ; Invoke the system call

8. Photolithography is a process of using light to transfer precise patterns onto a light-sensitive material. This material is 
a photoresist coating on a substrate which is typically a silicon wafer. A combination of UV light, a photomask, and tiny amounts
of etching are used to create these patterns. A photmask has the pattern that's transferred onto the material. This process is used 
in manufacturing microelectronics and integrated circuits. The node used to create the transistors of the CPU is 14 nm.
